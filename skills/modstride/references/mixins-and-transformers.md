# Mixins and access changes

Inventory mixin configuration, side, priority and targets. Check owner, descriptor, injection kind, ordinal, local capture, control flow and match count against the target bytecode. Validate the remapped artifact because dev and production namespaces can differ. Prefer a supported loader event when its timing and cancellation match. [Mixin architecture](https://github.com/SpongePowered/Mixin/wiki/Introduction-to-Mixins---Understanding-Mixin-Architecture)

For access widening or access transformation, identify the effect, such as exposing a private member, permitting inheritance or removing finality. Verify namespace, descriptor, syntax, metadata and build registration. Newer Fabric class tweaker features require specific Loader and Loom versions. [Fabric access widening](https://docs.fabricmc.net/develop/class-tweakers/access-widening) · [Forge 1.20.1 access transformers](https://docs.minecraftforge.net/en/1.20.1/advanced/accesstransformers/)

Launch each supported side and exercise each transformed path. Inspect logs for failed injections and test combinations with mods that touch the same code paths.
