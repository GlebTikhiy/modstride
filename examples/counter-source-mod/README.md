# Field Counter

An original MIT-licensed Fabric item. Right-clicking a Field Counter on the logical server increments the held stack's own count and displays it in the action bar. The stack limit is one. In the 1.20.4 version the count is stored in the ItemStack tag. In the 1.20.6 port it lives in the `minecraft:custom_data` component under the same key.

See the [0.2.0 development report](../../docs/development-0.2.0.md) for the migration, runtime commands and evidence.
